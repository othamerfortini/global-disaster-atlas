# GDACS adapter

Phase 0.3 role: discover and enrich global earthquake, cyclone, flood, volcano and related event records.

GDACS provides a public API with event search, event detail, affected locations, impact analysis, timelines, polygons and population-exposure endpoints. Exposure/model outputs must remain explicitly classified as modeled/estimated and must not be converted into observed casualty counts.

Bulk/raw redistribution is not assumed. Preserve source identifiers, retrieval timestamps and the applicable GDACS terms/attribution.
